# CareConnect

A web-based family care coordination system for older adults in Nepal.
CareConnect helps local and distant relatives share updates, assign
responsibilities and follow up on appointments for an older parent or
grandparent, all inside a private family circle.

Final Year Project (CS6P05NP), London Metropolitan University,
Informatics College Pokhara.

## Core features
- Private family circles with role-based access
- Attributed wellbeing check-ins (author and time recorded)
- Task assignment with due dates and status
- Appointment records, attendance and follow-up notes
- Explainable flags for overdue tasks and missing check-ins
- Shared dashboard and activity history

## Tech stack
React + Vite, Node.js, Express, MongoDB (Mongoose), Zod, Jest, Supertest

## Out of scope
Diagnosis, continuous monitoring, payments and emergency response.
